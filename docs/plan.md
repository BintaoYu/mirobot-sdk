# Mirobot SDK 计划

当前仅确定[模块与编译组合边界](architecture.md#模块边界与编译组合设计)，不拆分源码、修改构建/stage 或新增设备功能。
后续获准实施模块化时，先核对 `common` 内通信/会话/异步适配的真实依赖与公共 ABI，再按实际消费需求决定构建粒度和可选后端。
验证需覆盖最小依赖、关闭未选设备/传输、公开 staged 消费与共享 UDP/worker 的停止清理；兼容变更须同步迁移。

维护改动遵守[消费边界](architecture.md#消费方与边界)，最近验证见[状态](status.md)。
Motor / Mirobot 现场验收由各消费应用明确设备、动作和停止责任；本仓库的独立构建与硬件测试见[构建指南](building.md)。
